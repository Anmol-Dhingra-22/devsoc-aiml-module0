# Task 2 — Linear Regression

This project implements a linear regression model from scratch using Python and NumPy.

## Implementation
- Data exploration and preprocessing
- One-hot encoding and feature normalization
- Mean Squared Error (MSE) loss function
- Gradient descent for training
- Evaluation using unseen test data

## Results
- Training MSE: 0.4854
- Testing MSE: 0.8003

The implementation and results are available in the accompanying Jupyter notebook.
